Privacy Policy

Effective date: October 12, 2026

Starter draft: before publishing, check every statement against the actual app and replace the support-email placeholder. Do not claim practices the software does not follow.

1. Overview

ReachPilot is a desktop application that helps its operator manage authorized Gmail accounts and send email through Google's Gmail API.

2. Information handled

  • Google account information: the account email address, when available, to identify the authorized account.
  • OAuth credentials: tokens needed to connect to Gmail. The current desktop design stores token files locally in the application's user-data folder on the computer running ReachPilot.
  • Message information: recipients, subject, body, and other fields entered or imported by the operator for sending.
  • Settings and logs: account configuration, campaign settings, and operational status or error details generated by the app.

3. Google API data and use

ReachPilot requests the Gmail sending permission (https://www.googleapis.com/auth/gmail.send) and uses it to send messages configured by the operator. The intended function does not require reading inbox messages or using Gmail data for advertising.

ReachPilot's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google handles OAuth consent under Google's own terms and privacy policy.

4. Storage and sharing

OAuth token files and application data are intended to remain on the operator's local computer. Before publishing, confirm whether any version sends account data, message data, logs, or tokens to a server, analytics provider, crash-reporting service, or other third party. If it does, revise this policy to accurately disclose those transfers and purposes.

ReachPilot does not sell Google user data. Google API data is not used for targeted advertising. Any sharing necessary to provide the user-requested sending function must be limited to that function and consistent with Google's policies.

5. Retention and deletion

The operator can remove connected accounts and locally stored authorization files using account-management features where available, and can revoke ReachPilot access through Google Account security settings. Backups or exported files created separately may need to be deleted separately.

6. Security

Keep the computer account protected and do not share OAuth token files. No electronic storage method is perfectly secure. If unauthorized access is suspected, revoke the app's access in the Google Account.

7. Children's privacy

ReachPilot is not designed for children under 13, and we do not knowingly seek to collect personal information from children.

8. Changes

This policy may be updated to reflect changes in features or data handling. The effective date will be updated when a material revision is published.
